## 3. Audited Findings Detail

### Finding FR-SEC-001: AST Validation Sandbox Escape in Expression Evaluator
1. **ID and Severity**: `FR-SEC-001` | **CRITICAL**
2. **Category**: Security
3. **Location**: `flexirule/ruleflow/core/permissions.py:186-235` (`SafeEvalVisitor`)
4. **Evidence**: `SafeEvalVisitor` walks Python AST nodes and throws `ValidationError` whenever an attribute or identifier begins with `__` (dunder), or if `Import` / `ImportFrom` statements are encountered.
5. **Impact**: Prevents sandbox escapes via `__class__.__base__.__subclasses__()` in condition and assignment expressions.
6. **Root Cause**: Fixed previously; AST visitor pattern replaces vulnerable regex/syntax-only checks.
7. **Native Frappe Alternative**: `frappe.safe_eval()` with RestrictedPython.
8. **Version Compatibility**: Frappe v15 / v16.
9. **Recommendation**: Maintain `SafeEvalVisitor` as primary AST security gateway.
10. **Tests**: `test_permissions.py::test_FR_SEC_001_ast_validation_stub_sandbox_escape`.
11. **Confidence**: Confirmed (Fixed & Verified).

### Finding FR-SEC-002: Server-Side Template Injection (SSTI) in Document Actions
1. **ID and Severity**: `FR-SEC-002` | **CRITICAL**
2. **Category**: Security
3. **Location**: `flexirule/ruleflow/core/action_handlers/document_action.py:642-655` (`_render_scalar`, `_template_context`)
4. **Evidence**: Template rendering context is restricted to `{"doc": ..., "vars": ...}`. Global `frappe` module is no longer exposed to Jinja environments.

7. **Native Frappe Alternative**: `frappe.render_template(template, context, is_safe=True)`.
8. **Version Compatibility**: Frappe v15 / v16.
9. **Recommendation**: Keep Jinja context explicitly restricted.
10. **Tests**: `test_FR_SEC_002_ssti_in_document_action_rendering`.

### Finding FR-SEC-004: Background Worker User Context Defaulting
1. **ID and Severity**: `FR-SEC-004` | **HIGH**
2. **Category**: Security
3. **Location**: `flexirule/ruleflow/core/permissions.py:136-150`
4. **Evidence**: In background job queues, `frappe.session.user` defaults to `Administrator`, allowing rules triggered asynchronously to bypass user-level role checks.
5. **Impact**: Unprivileged users triggering background rules could cause actions to execute with full Administrator permissions.
6. **Root Cause**: Background task runner does not propagate initiator's user session.
7. **Native Frappe Alternative**: `frappe.set_user(context.user)` before executing rule logic in workers.
8. **Version Compatibility**: Frappe v15 / v16.
9. **Recommendation**: Forward trigger user context in queue payload and call `frappe.set_user()`.
10. **Tests**: `test_permissions.py`.
11. **Confidence**: Confirmed (Documented / Open).

### Finding FR-DATA-002: Active Version Concurrency Row Locking
1. **ID and Severity**: `FR-DATA-002` | **MEDIUM**
2. **Category**: Data Integrity / Concurrency
3. **Location**: `flexirule/ruleflow/doctype/rule/rule.py:1874-1904` (`validate_single_active_version`)
4. **Evidence**: `validate_single_active_version` uses `frappe.get_all("Rule", filters={"base_rule_name": self.base_rule_name, "is_active": 1, "name": ["!=", self.name]})` without row locking (`FOR UPDATE`).
5. **Impact**: Concurrent activations of rules within the same lineage can pass validation simultaneously, leading to multiple active versions.
6. **Root Cause**: `frappe.get_all()` does not acquire row locks.
7. **Native Frappe Alternative**: `frappe.qb.from_("Rule").where(...).for_update()`.
8. **Version Compatibility**: Frappe v15 / v16.
9. **Recommendation**: Migrate `validate_single_active_version` query to Frappe Query Builder with `.for_update()`.
10. **Tests**: Concurrency tests in `test_rule_versioning.py`.
11. **Confidence**: Confirmed (Documented / Open).

### Finding FR-PERF-001: N+1 Query Pattern in Child Table Appends
1. **ID and Severity**: `FR-PERF-001` | **HIGH**
2. **Category**: Performance
3. **Location**: `flexirule/ruleflow/core/action_handlers/document_action.py:517-584` (`_apply_table_mappings`)
4. **Evidence**: Iterates over row items calling `doc.append(table_field, row_payload)` individually for each mapped row.
5. **Impact**: For child tables with hundreds of rows, individual row validation and schema lookups introduce high CPU and DB overhead.
6. **Root Cause**: `Document.append()` triggers row-level meta resolution on each call.
7. **Native Frappe Alternative**: Batch payload preparation into a single list assign (`doc.set(table_field, row_list)`) or optimized child table bulk extend.
8. **Version Compatibility**: Frappe v15 / v16.
9. **Recommendation**: Construct list of child dict payloads and populate via single `doc.extend()` or `doc.set()`.
10. **Tests**: Benchmark tests in `test_document_action.py`.
11. **Confidence**: Confirmed (Documented / Open).

## 4. Native Frappe Framework API Comparison Matrix

| Area | FlexiRule Custom Implementation | Native Frappe Alternative | Recommendation & Decision |
| :--- | :--- | :--- | :--- |
| **Expression AST Validation** | Custom `SafeEvalVisitor(ast.NodeVisitor)` | `frappe.safe_eval()` | **Retain Custom**: Native `safe_eval` uses RestrictedPython which alters execution semantics; custom AST visitor provides domain-specific dunder and import security without execution overhead. |
| **Active Version Locking** | `frappe.get_all("Rule", filters=...)` without lock | `frappe.qb.from_(Rule).where(...).for_update()` | **Adopt Native**: Replace `frappe.get_all` in `validate_single_active_version` with Query Builder `.for_update()` to prevent concurrent active rule race conditions. |
| **Action Plan Caching** | Redis key pattern deletion | `frappe.cache.delete_value()` / `delete_keys()` | **Adopt Native**: Standardized on native Frappe CacheManager API to ensure compatibility with Redis cluster environments. |
| **Jinja Context Sanitization** | Manual dictionary context stripping in `_render_scalar` | `frappe.render_template(..., is_safe=True)` | **Retain Custom Context**: Explicit context scope (`doc` and `vars`) guarantees SSTI protection across all Jinja evaluation points. |
| **Child Table Appends** | Sequential `doc.append()` loop | `doc.set(table_field, row_list)` | **Adopt Native**: Batch child table row payloads into a single `doc.set()` call to eliminate N+1 metadata resolution calls. |
| **Workspace Custom Docs** | `hide_custom: 1` in `ruleflow.json` | Frappe `hide_custom` field | **Leverage Native**: Native Frappe feature prevents custom doctypes from polluting standard module workspace. |
