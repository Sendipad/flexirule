# Contributing to FlexiRule

Thank you for your interest in contributing!

## How to contribute

- Open an issue for bugs, enhancements, or questions.
- Submit pull requests (PRs) for fixes or new features.
- Follow existing coding standards and folder structure.
- Add clear descriptions to your PRs.

## Development setup

1. Install Frappe v15+.
2. Clone this app into your bench.
3. Run bench start and begin testing.

## What we welcome

- Improvements to the rule engine.
- Process expansions.
- UI/UX improvements for the Rule Builder.
- Documentation and test cases.

## Communication

If you want to discuss ideas before contributing, open a GitHub Issue.
